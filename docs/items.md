# Предметы в редакторе Godot

Каждый предмет — ресурс `.tres` в `resources/items/`. Откройте его в FileSystem,
чтобы редактировать поля через Inspector. Старый `items.json` перенесён в эти
ресурсы и больше не используется. Все существовавшие значения сохранены.

| Поле | Назначение |
| --- | --- |
| `Item Id` | Уникальный идентификатор |
| `Title` | Название в интерфейсе |
| `Description` | Описание карточки |
| `Category` | Категория данных; фильтрация пока не реализована |
| `Texture Path` | Путь к изображению; пустое значение оставляет цветную фигуру |
| `Size` | Число клеток по ширине и высоте |
| `Weight Kg` | Вес; `-1` означает, что вес не задан |
| `Price Credits` | Цена; `-1` запрещает торговлю |
| `Has Uses` | Можно ли расходовать предмет |
| `Uses Remaining` | Начальное число использований |
| `Properties` | Эффекты предмета |

Поддерживаемые эффекты в `Properties`: `fatigue_restore`, `satiety_restore`,
`water_restore`, `speed_bonus_percent`. Для расходуемых эффектов включите
`Has Uses` и задайте положительное количество. Бонус скорости применяется
к установленному двигателю. Новые типы эффектов требуют реализации в коде.

Для автомобильной детали также доступны `Model Name`, `Slot Type`
(`wheel`, `engine`, `transmission`) и начальное `Condition Percent`.
Параметр скорости вычисляется из `speed_bonus_percent`, отдельной копии бонуса нет.

Чтобы добавить предмет, продублируйте подходящий ресурс, задайте новый ID и
измените поля. Добавьте ресурс в `Initial Stock` торгового окна в `HUD.tscn`,
в `Order Cargo` ресурса баланса или в `Installed Parts` сцены автомобиля.
Само создание файла не добавляет предмет в игру.

Установочные размеры: колёса `2×2`, двигатель и трансмиссия `2×3`.
Для новой начальной детали выберите соответствующий элемент `Installed Parts`:
переднее левое, переднее правое, заднее левое, заднее правое колесо,
двигатель, трансмиссия. Установленная деталь должна подходить по типу и размеру.

Изображения находятся в `resources/item_images/`; выберите файл в `Texture Path`.
Изображение используется и в карточке, и в сетках инвентаря и деталей.
Внутриигровые экземпляры копируются из ресурсов: износ и расходование не меняют
шаблон. Новые значения применяются после следующего запуска игры.
