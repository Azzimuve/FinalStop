# Создание событий в пути

События находятся в `resources/travel_events.json`. Измените файл и запустите
игру заново: он загружается один раз при старте. Новые события с перечисленными
ниже последствиями не требуют изменения скриптов. Сам JSON включён в экспорт.

## Частота

В объекте `settings`:

| Поле | Значение | Назначение |
| --- | --- | --- |
| `check_interval_km` | 10 | Расстояние между проверками, строго больше нуля |
| `base_chance_percent` | 20 | Начальный шанс и шанс после события, от 0 (не включая) до 100 |
| `failure_increase_percent` | 20 | Прибавка после промаха; итог ограничивается 100% |
| `cooldown_km` | 15 | Пробег без проверок после события |

Первая проверка происходит после 10 км. После промахов шанс равен 40%,
60%, 80%, 100%. После события следующие 15 км не учитываются для проверок,
затем отсчитываются новые 10 км: первая проверка через 25 км после события.
Пробег накапливается в городе и между городами, сохраняется между поездками
и паузами в текущей игровой сессии. Загрузка новой игры начинает отсчёт заново.
Пока игрок читает окно, движения и расхода игрового времени нет.

## Добавление события

Скопируйте объект из массива `events`, измените `id`, заголовок, описание
и действия. Между объектами ставятся запятые, после последнего запятой нет.
JSON не поддерживает комментарии. Пример одного объекта:

```json
{
  "id": "my_find",
  "title": "Находка у дороги",
  "description": "Вы заметили брошенную сумку.",
  "weight": 1,
  "actions": [
    {
      "text": "Осмотреть — 20 мин.",
      "minutes": 20,
      "outcomes": [
        {"weight": 1, "text": "Найдено 40 кр.", "money": 40},
        {"weight": 1, "text": "Ничего полезного."}
      ]
    },
    {
      "text": "Проехать мимо",
      "outcomes": [{"text": "Вы продолжаете путь."}]
    }
  ]
}
```

Это пример для копирования, а не дополнительное событие в текущем наборе.

## Поля

У события обязательны уникальный непустой `id`, `title`, `description`
и непустой массив `actions`. `weight` — относительный вес выбора события,
по умолчанию 1, строго больше нуля. При весах 1 и 3 второе выбирается втрое
чаще первого. Это выбор типа события после успешной проверки общего шанса.

У действия обязательны `text` (подпись кнопки) и непустой массив `outcomes`.
Необязательные поля, по умолчанию ноль:

- `minutes`: длительность действия в игровых минутах.
- `fuel_cost`: сколько литров списать перед действием.
- `money_cost`: сколько кредитов списать перед действием.

При нехватке топлива или денег кнопка недоступна. У каждого события должно
быть хотя бы одно действие без денежных и топливных затрат, чтобы игрок
всегда мог разрешить событие. Время бесплатного действия может быть ненулевым.
Подписи кнопок редактируются вручную: укажите в них стоимость и длительность.

У результата обязательна строка `text`. Поддерживаются:

- `weight`: относительный вес результата, по умолчанию 1, больше нуля.
- `money`: полученные кредиты, по умолчанию 0.
- `fuel`: полученные литры, ограниченные вместимостью бака, по умолчанию 0.
- `fatigue_restore`: восстановление бодрости, ограниченное максимумом, по умолчанию 0.

Затраты, длительность и награды должны быть неотрицательными числами.
Равные веса двух результатов дают вероятность 50/50. Выбирается один результат.
Расходы списываются один раз, затем проходит время действия и выдаётся награда.
Время действия расходует бодрость, сытость и воду; при истощении возможен
существующий вынужденный сон. Повторный клик не применяет результат повторно.

После результата игрок нажимает «Продолжить путь». Маршрут и его прогресс
сохраняются; при пустом баке движение остаётся остановленным.

Ошибки JSON выводятся в журнал Godot. Некорректные события пропускаются;
неизвестные поля событий, действий и результатов тоже считаются ошибкой,
чтобы опечатки не игнорировались. Если пригодных событий нет, поездка
продолжается без них. Для нового вида последствий (предметы, репутация,
цепочки событий и т. п.) потребуется расширить обработчик и формат.

## Текущий набор

- Просьба о топливе: отдать 3 л за 60 кр. и 10 минут либо проехать мимо.
- Препятствие: расчистить за 30 минут либо объехать за 1 л и 10 минут.
- Найденная машина: осмотр за 20 минут, 50% получить 40 кр.; можно проехать мимо.

Все три события имеют одинаковый вес и могут повторяться после защитного пробега.
