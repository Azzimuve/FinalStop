# Roadmap

## Уже готово в прототипе

- [x] Глобальная и городская карты, точки интереса и маршрутизация.
- [x] Перемещение автомобиля, остановка, продолжение поездки и игровое время.
- [x] Камера карты: перемещение зажатой ЛКМ.
- [x] Топливо, заправка, деньги и настройки базового баланса.
- [x] Усталость: расход по игровому времени, штрафы скорости, сон и сигареты.
- [x] Доска из трёх заказов, выбор заказа, сроки, выплата и доставка груза.
- [x] Загрузка и выгрузка груза в инвентарь машины 24×8.
- [x] Ручная и автоматическая укладка, поворот предметов клавишей R.
- [x] Контекстное меню предмета по ПКМ: повернуть или выбросить навсегда.
- [x] Ограничение открытия инвентаря во время остановки.
- [x] Автомобиль с четырьмя колёсами, двигателем и трансмиссией.
- [x] Состояние деталей в процентах, ремонт и замена деталей.
- [x] Диагностика: бесплатно в гараже и за 50 кр. в мастерской.
- [x] Улучшение автомобиля: снятие и установка деталей, стоимость 400 кр.
- [x] Запрет принятия пустой работы или работы с неполным комплектом деталей.
- [x] Торговля в мастерской и магазине переносом между инвентарями.
- [x] Тестовый товар магазина: сигареты 1×1 за 20 кр.
- [x] Модальные окна с единым порядком наложения интерфейсов.
- [x] Компактная панель заказа и кнопка инвентаря под картой заказа.

## Следующий этап

- [ ] Расширить ассортимент магазина и мастерской.
- [ ] Добавить полноценные типы товаров, стоимость и ограничения торговли.
- [ ] Реализовать расширенный груз: вес/объём, припасы и предметы заданий.
- [ ] Добавить поломки и последствия нулевого состояния деталей.
- [ ] Настроить баланс ремонта, износа, деталей, торговли и заказов.
- [ ] Реализовать исследование окрестностей и здания с вариантами действий.
- [ ] Добавить события в пути и их последствия.
- [ ] Добавить пассажирские, срочные и специальные заказы.
- [ ] Реализовать репутацию и последствия неполной доставки.
- [ ] Добавить обучающую последовательность компании.
- [ ] Реализовать переход к самостоятельному путешествию.

## Открытые решения

- [ ] Точная модель динамических цен и спроса между городами.
- [ ] Состав и правила использования еды, воды, лекарств и других ресурсов.
- [ ] Сюжетный выбор: выкуп, кража автомобиля или альтернативный путь.
- [ ] Финальный состав MVP и количество контента для первой версии.
